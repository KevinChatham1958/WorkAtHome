What It Is

Use Claude Code to build a tiny one-page web tool that answers one specific question people already search for, then earn from affiliate links shown right after the answer. The creator's example is a home gym fit checker: you enter room length, width and ceiling height, and it tells you which racks, benches and barbells fit, then links to racks that do fit a low ceiling. He first has Claude Code build a data file of real equipment dimensions (with the instruction to leave gaps blank rather than estimate), then a single HTML page, which he checks by hand and puts on a free host. Traffic comes from a faceless Shorts channel about the problem (not the tool), using AI-written 60-second scripts, screen recordings of the tool and AI voiceover, with the tool link in the first line of the description and pinned comment.

The Pitch

The creator argues that client work, automations, software products and app audits all require you to already be a salesperson, on call, technical or credible, while small self-contained tools are exactly what Claude Code builds best and need no clients or upkeep. He picks niches by search data, citing "home gym small space" at about 5,000 monthly searches with low competition, and says expensive equipment means one affiliate sale pays far more than a cheap ebook.

Who It’s Best For

Patient beginners comfortable checking numbers and making simple faceless short videos, who can wait for traffic to build.

The Truth (as we see it)

Building a simple tool with an AI coding assistant is genuinely cheap now, and the creator's warning to verify every number before publishing is sound, since a wrong answer costs a real buyer money. The hard part, as he admits, is getting visitors: the tool earns nothing until the Shorts channel brings traffic, and most new channels grow slowly. Affiliate commissions on fitness gear vary widely and are often small percentages, and the search figures he quotes come from an unnamed keyword tool. He promotes ViralsScope, a video-idea scoring tool, through a link in the description; the video does not say whether that is a sponsorship or affiliate deal.
