What It Is

You build an interactive wedding planning dashboard with Claude Code and sell it on Etsy, Gumroad or similar. You first plan in Claude chat (with a cheaper model) to define the product type, the buyer, the home screen, tabs, local-browser storage, single HTML file output and design style, feeding it screenshots of best-selling listings. Claude Code then builds the file; you click every button to test it, publish a live preview via GitHub and Vercel, and make mockups by dropping screenshots into Google's Flow tool. The product delivered is two files: the index.html dashboard and a PDF with instructions and the preview link.

The Pitch

The creator shows an interactive wedding dashboard listing that gained traction within a month of launch, per the Profit Tree spy tool. She argues many buyers find Google Sheets intimidating, so a clean interactive version stands out from static planners.

Who It’s Best For

Organized, detail-minded people who like testing and polishing a product and want a digital item that is different from typical spreadsheets.

The Truth (as we see it)

This is a realistic, low-cost way to make a more modern version of a popular planner, and the build steps shown are accurate. Expect to spend time debugging and answering buyer questions about opening an HTML file. Sales claims about the competitor listing are estimates, not audited data. Delivery is an index.html file plus a PDF with instructions and a live preview hosted free on GitHub and Vercel; data is saved in the buyer's browser, so the creator stresses telling buyers to use the downloaded file, not the preview link. Claude Code requires a paid plan (about $20 a month). The creator sells a paid membership (AI Profit Lab) built around this kind of product and promotes it in the video, including ready-made prompts, and the revenue numbers come from the Profit Tree spy tool, which she also promotes.

Our assessment, based on the video and what’s typical across similar videos. We don’t independently verify income claims or prices.
